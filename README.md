# BlankNumGen

Генератор пустых страниц PDF с номерами. Windows-приложение (нативный GUI)
и консольный режим для скриптов.

Пример: вводите последовательность `1,2,6-9,42-43` — получаете PDF из 8 пустых
страниц, на которых в выбранном месте напечатаны числа 1, 2, 6, 7, 8, 9, 42, 43.
Именно такой файл удобно подкладывать под сканы или печатать на плотной бумаге,
чтобы пронумеровать вкладки/листы.

## Сборка

Из исходников нужен только Go (1.22+). Кросс-сборка из Linux/macOS делается
одной командой, внешних зависимостей и CGO нет:

```bash
make windows        # dist/blank_num_gen.exe (x64) и dist/blank_num_gen-32.exe (x86)
make cli            # консольный вариант blank_num_gen-cli.exe
```

Или напрямую:

```bash
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -trimpath \
  -ldflags "-s -w -H=windowsgui" -o blank_num_gen.exe .
```

Получается один статический `.exe` примерно на 10 МБ: подключать ничего не нужно,
достаточно запустить файл. В сборку встроены шрифты DejaVu Sans (для кириллицы
в тексте «до/после номера»), поэтому размер растёт.

Готовые файлы: `dist/blank_num_gen.exe`, `dist/blank_num_gen-32.exe`,
`dist/blank_num_gen-cli.exe` — в репозиторий они не коммитятся, а собираются
в CI (`.github/workflows/build.yml`): каждый пуш запускает сборку на
`windows-latest`, тег вида `v1.0.0` дополнительно создаёт GitHub Release и
прикладывает туда все три `.exe`. Иконка приложения лежит в `app.ico` и встраивается
при сборке (файл `rsrc_windows_*.syso`); пересобрать её можно командой
`make icon` — она рисуется кодом из `tools/mkicon`.

## Интерфейс

* **Последовательность номеров** — номера через запятую и диапазоны через дефис:
  `1,2,6-9,42-43`. Поддерживаются пробелы, переводы строк, точка с запятой,
  длинное тире, обратные диапазоны (`9-6` → 9, 8, 7, 6), опция «Убрать
  повторяющиеся номера». Каждый номер становится отдельной страницей.
* **Страница** — A3, A4, Letter, Legal, A5 или свой размер в мм; альбомная
  ориентация.
* **Расположение номера** — по горизонтали (слева / по центру / справа) и по
  вертикали (сверху / по центру / снизу), то есть сетка 3×3, плюс независимые
  отступы слева/справа и сверху/снизу в мм.
* **Номер** — гарнитура (Helvetica, Times, Courier), размер в pt, жирный/курсив
  и цвет.
* **До номера / После номера** — произвольный текст, который печатается вместе с
  номером: в поле «До номера» можно ввести `Стр. ` (получится «Стр. 42»), в поле
  «После номера» — ` —` (получится «42 —») или, например, `/2019` → «42/2019».
  Пустые поля означают, что на странице будет только сам номер. Если в этих полях
  есть кириллица, приложение само подставит встроенный шрифт DejaVu Sans.
* **Предпросмотр** — миниатюра первой страницы с номером в выбранной позиции.

Настройки сохраняются в `%APPDATA%\blank_num_gen\settings.json`.

## Консольный режим

```bash
blank_num_gen-cli.exe -o pages.pdf -s "1,2,6-9,42-43" -pos bottom-center
```

| Флаг | Значение |
| --- | --- |
| `-o` | файл PDF (обязательный) |
| `-s` | последовательность номеров |
| `-size` | `A3`, `A4`, `Letter`, `Legal`, `A5` или `148x210` (мм) |
| `-landscape` | альбомная ориентация |
| `-pos` | `top`/`middle`/`bottom` и `left`/`center`/`right`, например `bottom-center` |
| `-margin-x`, `-margin-y` | отступы в мм |
| `-font`, `-pt`, `-bold`, `-italic` | оформление |
| `-color` | `black`, `gray`, `blue`, `red`, `green`, `orange`, … |
| `-prefix`, `-suffix` | текст до и после номера |
| `-dedupe` | убрать повторяющиеся номера |

## Разработка

```bash
make test    # go test ./... — тесты парсера, PDF, CLI и предпросмотра
make vet     # go vet для linux и windows
make fmt     # gofmt
```

Логика не зависит от платформы и покрыта тестами: `seq.go` (разбор
последовательности), `pdfgen.go` (генерация PDF), `preview.go` (миниатюра),
`cli.go` (консольный режим). GUI — `gui_windows.go` (сборка через
[walk](https://github.com/lxn/walk), PDF — [go-pdf/fpdf](https://github.com/go-pdf/fpdf)).

Шрифты: `assets/fonts/DejaVuSans*.ttf`, лицензия — `assets/fonts/LICENSE-DejaVu.txt`.
